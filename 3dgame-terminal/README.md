# Neon Maze

A small dependency-free 3D raycasting shooter for the Windows console, written in Python.

## Run

```powershell
python main.py
```

## Controls

- `W` / `S`: move forward / backward
- `A` / `D`: turn left / right
- `Q` / `E`: strafe left / right
- `Space`: fire
- `R`: restart after a win or loss
- `Esc`: quit

Clear every hostile and walk onto the `X` exit.
