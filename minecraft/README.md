# VoxelCraft prototype

A first playable Minecraft-style voxel prototype built with Pygame.

## Run

```powershell
python -m pip install -r requirements.txt
python main.py
```

## Controls

- **WASD / arrow keys:** Move the camera
- **Left mouse button:** Mine the block under the cursor
- **Right mouse button:** Place the selected block on top of a block
- **1-4:** Select grass, dirt, stone, or wood
- **Close the window:** Quit

The current version uses an isometric renderer and simple colored faces. Future versions can add a first-person camera, textures, chunk loading, player physics, lighting, inventory, and save files.
